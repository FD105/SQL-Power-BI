# SQL und Power BI

In diesem Repo werden die Daten mittels SQL auf Probleme untersucht. Diese können in Form von NULL-Werten oder Ähnlichem vorliegen. Anschließend werden Queries formuliert, welche die Daten bereitstellen, die am besten für eine Repräsentation in Power BI geeignet sind.

Die gegebenen Daten behandeln das Thema der Fehlzeiten. In Power BI werden die aus den Daten hervorgehenden Merkmale in Grafiken aufbereitet, um aufzuzeigen, woraus sich die Fehlzeiten zusammensetzen. Dazu werden noch weitere Merkmale betrachtet. Der jetzige Umfang ist noch recht kurz gehalten. Es ließen sich mit den Daten noch weitere Grafiken erstellen.
