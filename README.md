# SQL und Power BI

In diesem Repo werden die Daten mittels SQL auf Probleme untersucht. Diese können in Form von NULL-Werte oder ähnlichem vorliegen. Anschließend werden Queries formuliert, welche die Daten bereitstellen, die am besten für eine Repräsentaion in Power BI geeignet sind.

Die gegebenen Daten behandeln das Thema der Fehlzeiten.
